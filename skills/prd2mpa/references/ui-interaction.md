## 2 七类页面模板

新增页面【强制】先匹配到一个模板；匹配不上才允许自定义并登记。

| 模板 | 骨架（自上而下） | 必须区块与尺寸 | 禁止项 |
| --- | --- | --- | --- |
| 列表页 4.2.1（最高频） | 页头（标题+右侧操作）→ 筛选区 → 批量条（选中后出现）→ 表格 → 分页（右下，与表格间距 16） | 筛选项 ≤4 个常驻，超出收「高级筛选」；每行 ≤4 控件且等宽；操作列 ≤2 个文字按钮；分页默认 10 条 | 批量条放页底；筛选区与表格重复边框/内边距；操作列超 2 个不收「更多」 |
| 详情页 4.2.2 | 返回+标题+状态 Tag → Descriptions → Tab（≤6）→ Tab 内容 | 返回在左上带图标；状态用浅底深字 Tag；Descriptions 1~3 列，标签 text-3；右上主操作 1 + 次 ≤2 | 用 disabled 表现只读（默认只读用 readOnly）；单对象基础编辑一律跳新页 |
| 新建/编辑页 4.2.3 | 返回+标题 → 表单区（最大宽 640px，靠左）→ 操作组（左对齐，组内次左主右） | 用于独立路由、草稿、多步骤、长时或复杂内容 | 按钮文案叫「编辑」就统一跳页（默认走 Modal） |
| 工作台 4.2.4 | 指标卡（一行 ≤4）→ 待办/通知两栏（各默认 5 条）→ 快捷入口（自适应网格，末行可留空） | 逾期置顶；未读用左侧圆点不加粗；每模块定义数据上限，超出走「更多」 | 首页承担完整批量管理；无目标时造「查看全部」；把 4 类当硬上限 |
| 数据看板 4.2.5 | 页头（时间范围+导出）→ 指标卡（一行 ≤6）→ 12 栅格图表（8+4、6+6、12） | 图表最小高 200px；同指标跨页配色一致；图表区有「暂无数据」空态 | 切时间范围时图表高度变化；类目 >12 仍用柱形图 |
| 设置页 4.2.6 | 左锚点导航 160px → 右侧分组表单 | 左右联动高亮；分组 ≤8，超出左侧改侧边 Tab | — |
| 结果页 4.2.7 | 图标 + 标题 + 一句说明 + 操作 | 最多 2 个操作；用于流程终态（提交成功、无权限、404） | 操作 >2；把权限不足标成系统错误 |

- 列表页筛选与表格可同容器也可分区，保持归属清晰；无权限场景给真实可用的申请/联系路径或返回。

## 3 组件选型

### 3.1 控件选择对照（按数据关系、比较必要性、可定位性、空间选）

| 数据与任务特征 | 控件 |
| --- | --- |
| 单选、选项短且需一眼比较、空间足够 | Radio 或互斥按钮组（选项保持可见） |
| 单选、需收纳或版面紧凑 | Select（短而稳定的选项可不带搜索） |
| 选项长/多，或按名称定位 | 支持搜索的 Select（说明加载、无结果、错误） |
| 有层级：省市区、组织架构 | 按路径选 Cascader；按节点选 TreeSelect |
| 是/否、立即生效 vs 随表单提交 | Switch（说明写入与失败恢复）vs Checkbox |
| 多选、能直接排列 vs 需收纳/搜索 | Checkbox 组 vs Select 多选（已选项可查看/移除） |
| 数值 / 日期 | InputNumber / DatePicker、RangePicker |
| 单行 / 多行 / 富文本 | Input / Textarea / Editor |
| 纯文字解释（≤20 字）vs 需点进去操作 | Tooltip（hover/focus、不可操作、移开消失）vs Popover（click、点外部或关闭消失） |

- 「2~5 项」「超过 5 项」只作初筛示例，不是自动切换控件或强制搜索的阈值。
- 中尺寸单行选择器（32px 高）：左侧文字内距 12px，右侧箭头盒 12×12、距内边界 12px，文字与箭头间隔 ≥8px，箭头不参与点击与 Tab。
- 【强制】禁止 Tooltip 放链接或承载唯一必要信息（键盘、触屏触达不到）。

### 3.2 按钮层级与尺寸档位

| 项 | 值 |
| --- | --- |
| 层级 | 主要 / 次要 / 虚框 / 线框 / 文本；危险操作用 danger + 具体后果（「删除 3 项」） |
| 中尺寸主要 Button | 高 32px、圆角 2px、内距 5px 16px、图文 gap 8px、图标 14px；主色 hover 6→5、active→7 |
| 尺寸档位（Input 高） | 大 36 / 中 32 / 小 28 / 迷你 24；同一操作组控件基线与高度协调 |

表格密度（同一表格保持统一密度，禁止把一个值当所有行高）：表头 / text 单元格 / Input 高为大 40/41/36、中 36/37/32、小 32/33/28、迷你 24/25/24；中尺寸表头 36px、padding 7px 16px、fill/2 底、14/22 Medium、border/2 分隔。

- 同一操作组只强调一个主要动作（页级「新建」与筛选组「查询」可分别突出）；【强制】主按钮只有一个，次操作 ≤2，超出收「更多」。
- Button-group 表示相关动作集合，不含互斥语义；互斥视图切换用 Radio 组/分段选择。

### 3.3 容器决策（Modal / Drawer / 独立页 / 确认框）

| 场景 | 优先容器 |
| --- | --- |
| 单对象局部微编辑（如单元格） | 行内 / Popover |
| 闭合的单步短任务 | Modal |
| 列表中单对象基础信息编辑 | **Modal【项目默认】**，保留列表筛选、页码、选择与滚动位置 |
| 持续对照列表、连续切换对象 | Drawer（明确遮罩与焦点是否阻断主页面） |
| 多分组、复杂校验、较大编辑表格 | 独立页，或容量足够的 Drawer |
| 分享/打印/草稿/复杂分步、需可回访链接 | 独立页 |
| 需同时操作主页面 | 行内 / 并排区域 / 经验证可交互的非模态面板 |
| 非阻断结果 | Message / Alert / Notification |

- 判定顺序：需可回访链接、草稿、多阶段、长时编辑或复杂关联 → 独立页；否则列表内单对象基础编辑且一个任务内可完成 → Modal；否则需持续对照/连续处理 → 评估 Drawer；其余短任务 Modal、微操作行内。字段数只作初筛。
- Modal 宽档：S400 简短确认 / M520 默认闭合任务（未指定时用）/ L720 较宽内容 / XL960 必要并排比较。Drawer 宽档：S320 / M480 单列快速编辑 / L720 / XL960，超出容量改独立页；不得把含遮罩的 1440 画布当面板宽。容器距视口四周默认 24px，窄屏可 16px，内容过高只滚内容区。

### 3.4 表单布局

| 条件 | 布局 |
| --- | --- |
| 一般连续填写 / 含富文本、表格、上传预览 | 单列（后者控件占满宽度） |
| 字段短、关联清楚、空间足够 | 可双列，不以字段数自动触发；每列等宽（12 栅格各 6） |
| 需纵向比对（期初/期末、计划/实际） | 双列，成对字段并排 |

- 标签默认在上（与控件间距 12px）；字段短且需横向紧凑（数字、日期、开关）时标签在左、右对齐、宽 80px；【强制】同一表单标签位置统一。
- 操作区：独立页操作组左对齐（次左主右）；弹窗/抽屉固定在底部右对齐，内容区独立滚动；独立页可跟随底部或吸底。
- 行内编辑表格仅当：同构多行、需同时比较/批量填写，且已定义行级校验、保存范围、批量失败恢复与键盘流；否则进详情编辑。

> 来源：5.1.2、5.2.1、5.2.2、5.3.1、5.3.3、5.5.1、5.5.3、6.1、6.2、6.3.1、6.3.2、6.3.4、6.3.5

## 4 弹窗与抽屉结构

- 结构：标题（h2 16/24，【强制】必须有，禁止「提示」「系统消息」）→ 可选描述（base 14/22，说明后果不重复标题）→ 内容区（超高超滚动）→ 底部操作区（固定，上带 1px border/2 分割）。
- 按钮顺序【强制】次操作在左、主操作在右；初始焦点给标题说明、首个字段或合适操作，表单不默认聚焦提交按钮；关闭后归还触发元素。
- 危险操作（删除/停用）默认聚焦「取消」，避免连击回车误删；按钮用 danger 并写具体后果。
- 默认只允许一个任务型 Modal/Drawer；「丢弃修改」确认可为短暂第二层，完成后焦点归还原容器；选择器、日期、Tooltip 不算第二层。
- 内容、错误、操作在目标视口可达；70% 视口仅作容量估算参考。校验失败保持输入、错误就近；服务端错误在表单级表达。
- 列表「编辑」默认交互【项目默认】：标题「编辑 + 对象」，回填当前记录；常规单列 M520，需文件摘要或双列 L720；底部右对齐「取消」「保存修改」；提交期间防重；成功后关闭并保留筛选、页码、条数与选择。

| 触发 | 确认任务 | 编辑任务 | 只读查看 |
| --- | --- | --- | --- |
| 关闭按钮 | 可用 | 可用，处理未保存修改 | 可用 |
| Esc | 取消/关闭 | 先关子浮层，再按未保存处理 | 关闭 |
| 遮罩点击 | 默认不执行确认动作 | 默认不关闭，避免误触丢输入 | 可关闭 |
| 浏览器返回 | 按路由 | 路由驱动，返回前保护未保存值 | 路由驱动，可返回关闭 |

> 来源：5.6、6.4.1—6.4.8

## 5 反馈方式选择

| 反馈 | 用于 | 阻断 | 位置 |
| --- | --- | --- | --- |
| 内联错误 | 字段校验 | 否（阻断提交） | 字段正下方 |
| Message | 操作即时反馈 | 否 | 工程反馈区，时长按信息长度与是否可操作 |
| Alert | 持续可见的状态说明、表单级错误 | 否 | 页面/区块顶部，可关闭 |
| Notification | 后台完成、持续或系统消息 | 否 | 通常右上，重要/可操作消息持续到关闭 |
| Modal | 必须用户决策 | 是 | 居中 |
| Result 结果页 | 流程终态 | — | 独立页 |

- 【强制】错误一律就近：字段错误在字段下方，行操作失败在该行，禁止统一用 Message 报字段错误。
- 成功提示能省则省：结果已在界面可见（列表多一行、开关变色）不再弹 Message；结果不在视野（「已导出，请到下载中心查看」）或有延迟时才用。
- Alert 用于持续性状态（「该数据源近 7 天未同步」）；Notification 用于持续/异步结果，包括用户主动触发的后台任务。

> 来源：5.6、6.5

## 6 危险操作与可逆性

| 级别 | 特征 | 交互 |
| --- | --- | --- |
| L1 可撤销 | 有明确逆操作 | 直接执行 + Message 内「撤销」（归档、置顶、标记已读） |
| L2 轻损失 | 删除但可恢复 | 一次 Confirm |
| L3 重损失 | 删除且难恢复/影响他人 | Confirm + 输入名称或数量验证 |
| L4 不可逆 | 涉资金/权限/生产数据 | Confirm + 输入验证 + 结果通知，或走审批流 |

- 先问能不能撤销再决定要不要确认；L1 优先直接执行（对外部影响或撤销不能消除后果时仍评估风险）。
- 撤销窗口默认给足 ≥10s，与短 Message 时长分开；可用持久结果区或回收站继续恢复。
- 【强制】危险按钮不默认聚焦；【强制】批量确认必须带数量（「删除选中的 12 项」），禁止「确定删除吗？」
- 确认文案结构：{动作}{对象名}？{后果}，例「删除技术部？该部门下 8 名成员将被移出」。

> 来源：6.4.3、6.6、7.8.3

## 7 批量操作与选择模式

- 行首复选框常驻；选中 ≥1 项后在表格上方出现批量条，表达「已选 N 项（范围）」+ 动作，超过 3 个动作收「更多」。
- 默认范围是当前页，表头复选框命名「选择当前页全部项」；只有真实支持跨页才提供「选择当前筛选结果全部 N 项」入口，并区分当前页全选与全结果选择、给出取消范围的方式。
- 翻页、排序、切换分组后默认清除当前页选择；选择集按稳定 ID 核对，不得用数组下标。
- 成功/失败/结果未知分别反馈：全部成功后清除已处理项；部分失败保留仍可见的失败项并给逐项原因；未知项先查状态再决定下一步（见 9.4）。
- 失败较多或异步任务可提供有权限控制的明细下载；重试只针对已确认可重试的失败项。

> 来源：6.7、8.2.4

## 8 异步与长任务

| 预估时长 | 交互 |
| --- | --- |
| <1s | 按钮 loading，无其他提示 |
| 1~10s | 按钮/相关区块 loading 与防重；不因一次提交把整页换成 Skeleton |
| 10s~2min | 进度条，允许在页面内继续操作其他内容 |
| >2min | 转后台任务 + Notification 通知结果，允许离开页面 |

- 提交后【强制】立即禁用按钮并进入 loading，防重复提交是底线；>2min 任务必须提供任务中心/结果页入口。
- 【强制】部分失败必须说明哪部分成功、哪部分失败，禁止笼统报「操作失败」。
- 只有服务端已持久化才可承诺离页继续；路由切换停止无用轮询，任务中心可恢复查询。

> 来源：6.8

## 9 全局状态与异常

核心原则：局部问题不升级成全局阻塞。

| 状态 | 呈现 | 操作 |
| --- | --- | --- |
| 加载 | 骨架屏（首次）/ 局部 Spin（刷新） | 无 |
| 空 | 插画 + 一句说明 + 最多 1 个主操作 | 新建 / 重置筛选 |
| 错误 | 图标 + 一句说明 + 重试 | 重试 / 返回 |
| 无权限 | 说明范围，申请入口按 7.6.2 | 真实可用的申请/联系路径或返回 |

粒度：整页首次加载 → 整页骨架屏；单区块加载 → 仅该区块骨架屏，其他区块正常渲染；关键数据失败 → 整页错误态 + 重试；次要数据失败 → 该区块降级「暂不可用」，页面其余可用；多区块同时失败 → 按是否导致主任务不可用判断，独立次要区块分别降级。

空态文案公式（【强制】说清是什么空、为什么空，不能只写「暂无数据」）：

| 场景 | 文案 + 操作 |
| --- | --- |
| 无数据 | 「暂无{对象}」+ [新建{对象}] |
| 筛选无结果 | 「没有找到符合条件的{对象}」+ [重置筛选] |
| 搜索无结果 | 「未找到「{关键词}」相关结果」+ [清空搜索] |
| 无权限 | 「你没有查看{对象}的权限」+ [真实可用的申请入口 / 返回] |

骨架屏 vs 转圈：首次加载、整块未就绪用 Skeleton；局部刷新、已有内容上的操作用 Spin。骨架形状接近真实内容（行数、高度）；加载 >3s 叠加「加载中…」；【强制】禁止整页长期转圈（>3s 未出内容）与骨架长期占位无恢复路径。

| 错误级别 | 示例 | 呈现 | 用户可做 |
| --- | --- | --- | --- |
| L1 字段级 | 必填未填、格式错 | 字段下方红字 | 就地修改 |
| L2 操作级 | 提交/删除失败 | Message / Alert + 重试 | 重试、修改后重试 |
| L3 区块级 | 某模块数据加载失败 | 区块内错误态 | 重试该区块 |
| L4 页面级 | 页面主数据失败 | 整页错误态 | 重试、返回列表 |
| L5 应用级 | 主任务整体不可用 | 应用级提示，保留可用导航/草稿 | 重连、返回、稍后再试 |

- 每级错误【强制】给出下一步动作，禁止只报「操作失败」；说明原因（「网络连接失败」优于「请求失败」），但不暴露错误码与堆栈。
- 写入超时/断网时结果未知，不得直接标失败并重发：先查任务或对象状态，用幂等键/服务端去重（10s、最多 1 次只是默认建议）；网络恢复后重查数据并保留未保存输入，不自动整页刷新清空表单。

错误页文案：404「页面不存在或已被移除」→ 返回首页/上一页；500「服务器开小差了，请稍后重试」→ 刷新/返回首页；无权限页「你没有访问该页面的权限」→ 真实申请/联系路径或返回；维护中「系统维护中，预计 {时间} 恢复」→ 无操作或联系管理员。【强制】错误页必须有导航出口，禁止只放一句话让用户卡死。

> 来源：9.1—9.5、7.6.2

## 10 表格四态与加载落位

【强制】四态都保留表头可见（无权限态除外），否则用户不知道这张表是什么。

| 状态 | 呈现 | 操作 |
| --- | --- | --- |
| 加载中 | 首次加载骨架屏，行数 = 当前页容量；刷新用表格上方细进度条或局部 Spin | 无 |
| 空·无数据 | Empty 插画 + 「暂无数据」+ 主操作（如「新建订单」） | 新建 |
| 空·筛选无结果 | 空状态 + 「没有找到符合条件的结果」+「重置筛选」 | 重置 |
| 错误 | 错误图标 + 「加载失败」+「重试」 | 重试 |
| 无权限 | 说明范围，表体不披露无权数据 | 申请/返回，见 7.6.2 |

- 【强制】「无数据」与「筛选无结果」是两种空态：筛选无结果引导「重置筛选」，不要让用户去「新建」。
- 骨架行数与真实内容高度接近，完成时不大幅跳动；骨架保留表头、只替换表体；错误态必须给「重试」。
- 记录数为 0 时保留表头与当前条件；横向滚动时标识列固定左、操作列固定右，无溢出或已到边界时不保留固定列阴影。

> 来源：8.4、8.2.4、8.1.1、8.1.4

## 11 常见反例库（6.9，AI 最易犯）

1. 多分组、编辑表格、复杂校验挤进小 Modal → 按 6.1 改独立页或合适 Drawer。2. 长流程无进度、不能回退、切步丢数据 → 明确状态与恢复，复杂任务走独立页。3. 连续嵌套多个任务容器导致焦点混乱 → 一个主容器，确认后归还原焦点。4. 遮罩/关闭直接丢弃未保存输入 → 关闭前保留或确认。5. 危险操作被默认 Enter 误触发 → 危险按钮不初始聚焦并说明后果。6. 删除只写「确定删除吗」→ 标明对象、数量、影响与恢复条件。
7. 低影响可靠可撤销的操作反复确认 → 直接执行并给足撤销入口。8. 所有字段错误只报一条 Message → 错误关联字段，必要时加汇总。9. 已明显可见的变化反复弹成功提示 → 保留必要状态反馈。10. 同一表单标签关系混乱 → 按信息分组统一标签布局。11. 用 opacity 覆盖整块禁用组件 → 沿用组件禁用属性。12. 比较数值难以纵向扫描 → 数字对齐并用等宽数字，标识文本另处理。
13. 提交期间可连续重复请求 → 前端防重 + loading + 服务端幂等。14. 批量部分失败只显示「失败」→ 区分成功/失败项并给恢复路径。15. 状态仅由色点表达 → 补文字/图标语义。16. 完整对象详情塞进狭小确认框 → 整页或足够容量面板并保留回访入口。17. 必需选择控件只有 hover 才出现 → 常驻或提供可发现、键盘可达入口。18. 需同时操作主页面却被 Drawer 遮罩阻断 → 验证并排/行内/无阻断面板。

> 来源：6.9
