# UI 交互执行摘要（原规范第 4/5/6/9 章压缩版）

> 本文件压缩《UI规范文档》（2026-11 版，v4.0）第 4/5/6/9 章，并引用第 3 章 Token 与第 11 章约束；与原文冲突以原文为准。
> 用户自带 UI 规范时先按 [custom-ui-spec.md](custom-ui-spec.md) 处理，再照本文件结构重做一份项目版。
> 标注：【项目默认】= 无特定要求时采用，局部调整需说明用途与适用范围；【强制】= 不得偏离（0.3）。单位均为 px；出处为章节号。
> 落地 antd 6（工程参数参考 6.6.8）：控件高度按 24/32/40 档覆盖；列表 Table 用 size="medium"；Modal 默认 width 520；Drawer 预设 default 378 / large 736；不用 middle，改用 medium（3.2.3、5.1.2、6.2）。

## 3 应用框架（4.1.1—4.1.3）

| 框架 | 结构 | 选择依据 |
| --- | --- | --- |
| A 侧边导航式【项目默认】 | 全宽顶栏 + 左侧导航 + 右侧内容 | 模块较多、存在层级、经常切换任务 |
| B 顶部导航式 | 顶部主导航 + 下方内容 | 模块少且扁平，不压缩主要内容 |

标题区结构：页面标题（20/28、600）+ 右上角 [次操作][主操作]，下方可选一句说明（`colorTextTertiary` 14px）。

- 【强制】标题用具体名词（"订单列表""客户详情"），禁止"信息管理"这类空泛词；操作区在右上角、主操作最右，无操作时不留空操作区（4.1.3）。
- 导航层级优先简单，超过 3 级先评估搜索/分组与信息架构；侧栏可独立滚动，折叠后保留名称、图标与子菜单入口（4.1.2）。
- 有路径上下文时提供面包屑，用户区在顶栏右侧；亮色 Header/Sider 需显式配置，不套 SDK 默认深色导航与 50px 内距（4.1.2）。

## 4 响应式与断点（4.3）

| 视口宽度 | 布局行为 |
| --- | --- |
| ≥1600（xxl） | 阅读内容最大 **1440px 居中**；数据工作区可流式；表单不无意义拉长 |
| 1200—1599（xl） | 标准桌面，内容边距 **24px**；筛选按最小宽折行 |
| 1024—1199（lg 内项目区间） | 边距 **16px**、导航默认折叠 **80px**；Card / Descriptions 按空间减列 |
| 992—1023（lg 内受限区间） | 受限桌面模式，导航可展开；表格横滚，复杂编辑优先独立页 |
| 768—991（md） | 导航以可展开**面板**呈现；主内容保留，**表格横滚**，必要操作可达 |
| 576—767（sm） | 不承诺完整桌面编辑；**单列、16px 边距**，保留阅读/返回与必要操作路径 |
| <576（xs） | 极窄支持**按任务声明**；不静默删除必要字段，不制造无出口提示 |

- 1024px 是项目任务支持阈值，不等于 Ant Design 的 lg 断点；Modal 四周默认 24px，<768px 可 16px（4.3、6.2）。

## 5 页面密度（4.4）

| Table size | cell 上下/左右 padding | 文字 | 单行基础高度（含 1px 下边界） |
| --- | --- | --- | --- |
| large（SDK 默认） | 16/16 | 14/22 | 约 55 |
| **medium（列表默认）** | **12/8** | 14/22 | **约 47** |
| small | 8/8 | 14/22 | 约 39 |

- 【强制】同一表格密度统一；行含多行文本、Tag、头像或控件时可增高，不设固定高度裁切内容（4.4）。
- Table 的 size 与表单控件尺寸分别配置，不能把 32px 控件高度当行高；密度切换后重算固定列与阴影（4.4）。

## 6 七类页面模板（4.2.1—4.2.7）

新增页面【强制】先匹配一个模板，匹配不上才自定义并登记。

| 模板 | 骨架（自上而下） | 关键尺寸与规则 | 禁止项 |
| --- | --- | --- | --- |
| 列表页 4.2.1（最高频） | 页头 → 筛选区 → 批量条（选中后出现）→ 表格 → 分页 | 筛选项 ≤4 常驻、每行 ≤4 控件；批量条在**表格上方**；操作列 ≤2 文字按钮；分页**右下、与表格间距 12px** | 批量条放页底；筛选与表格重复边框内距；按 8 列硬截 |
| 详情页 4.2.2 | 返回 + 标题 + 状态 Tag → Descriptions → Tab（≤6）→ Tab 内容 | 返回在左上带图标；Tag 浅底深字；Descriptions **1~3 列**、标签 text-tertiary；右上主操作 1 + 次 ≤2 | 用 disabled 表现只读（用 readOnly）；单对象基础编辑一律跳新页 |
| 新建/编辑页 4.2.3 | 返回 + 标题 → 表单区（最大宽 **640**，靠左）→ 操作组 | 操作组左对齐，组内次左主右；是否吸底按可视高度与提交频率 | 按钮叫"编辑"就统一跳页（默认走 Modal） |
| 工作台 4.2.4 | 指标卡（一行 **≤4**）→ 待办/通知两栏 → 快捷入口 | 待办默认 5 条、逾期置顶；通知默认 5 条、未读圆点；快捷入口自适应网格末行可留空 | 首页承担完整批量管理；无目标造"查看全部"；把 4 类当硬上限 |
| 数据看板 4.2.5 | 页头（时间范围 + 导出）→ 指标卡（一行 ≤6）→ 24 栅格图表 | 图表最小高 **200**；常用 16+8 / 12+12 / 24；同指标跨页配色一致 | 切时间范围时图表高度变化；图表区无"暂无数据"空态 |
| 设置页 4.2.6 | 左锚点导航 **160** → 右侧分组表单 | 左右联动高亮；分组 ≤8，超出左侧改侧边 Tab | — |
| 结果页 4.2.7 | 图标 + 标题 + 一句说明 + 操作 | 最多 **2** 个操作；用于流程终态（提交成功、无权限、404） | 操作 >2；把权限不足标成系统错误 |

- 列表页筛选与表格可同容器也可分区，但归属清晰；无权限场景给真实可用的申请/联系路径或返回（4.2.1、4.2.7）。

## 7 组件选型（5.3.1、5.3.3、5.5.3、5.1.3）

按数据关系、同时比较的必要性、可定位性与可用空间选控件。

| 数据与任务特征 | 控件 |
| --- | --- |
| 单选、选项短且需一眼比较、空间足够 | Radio 或合适的互斥按钮组（选项保持可见） |
| 单选、需收纳选项或版面紧凑 | Select（短而稳定可不带搜索） |
| 选项长/多，或按名称定位 | 支持搜索的 Select（说明加载、无结果、错误） |
| 有层级：省市区、组织架构 | 按路径选 Cascader；按节点选 TreeSelect |
| 是/否，立即生效 vs 随表单提交 | Switch（说明写入与失败恢复）vs Checkbox |
| 多选、能直接排列 vs 需收纳/搜索 | Checkbox 组 vs Select 多选（已选项可查看/移除） |
| 数值 / 单个日期 / 区间 | InputNumber / DatePicker / RangePicker |
| 单行 / 多行 / 富文本 | Input / Textarea / Editor |

- "2~5 项""超过 5 项"只作初筛示例，不作为自动切换控件或强制搜索的阈值（5.3.1）。
- 中尺寸（32px 高）单行选择器：左侧文字起点到内边界 **12px**，右侧箭头盒 **12×12** 垂直居中且距内边界 **12px**，文字与箭头至少隔 **8px**；右侧文字预留 **32px**；箭头不挡点击、不单独进 Tab；hover/focus/error/disabled 均保留箭头与留白（5.3.3）。
- 【强制】Tooltip 只放纯文字（≤20 字）、不可操作、移开消失；Popover 可含链接/表单、点击外部消失；禁止 Tooltip 装链接或承担唯一必要信息（5.5.3）。
- 状态必须齐全：默认/悬停/按下复用组件（主要按钮 **#1677FF → #4096FF → #0958D9**）；聚焦保留可见焦点、不移除唯一 outline；禁用用 disabled 且与触发一致，原因放附近文字或可达帮助、不用整块 opacity；加载防重并保持尺寸、不伪造百分比；校验错误分字段级与表单级，不只靠红/黄边框（5.1.3）。

## 8 按钮与操作组（5.2.1、5.2.2）

| 目的 | 实现 |
| --- | --- |
| 当前页面主要动作 | type="primary"，蓝底白字，**32px 高、6px 圆角** |
| 次要动作 | type="default"，白表面 + 描边 + 正常文字 |
| 文本 / 链接动作 | type="text" / "link"，按上下文区分操作与导航 |
| 添加类弱入口 | 需要时 type="dashed" |
| 危险动作 | danger + 合适 type，确认说明对象/后果 |
| 纯图标动作 | icon + 可访问名称 |

- 常态页面默认一个主要强调；筛选「查询」通常用 default，页级「新建」承担 primary（4.2.1、5.2.1）。
- Modal 打开后由当前任务承担主要动作，背景不可操作；分区确有独立目标时才可设分区主操作（1.6、5.2.1）。
- 【强制】主按钮只有一个，次操作 ≤2，超出收「更多」；危险与禁用是不同语义，不以透明度替代 disabled（5.2.1、7.4.1）。
- Button-group 表示相关动作集合，不含互斥语义；互斥视图切换用 Radio 组/分段选择（5.2.2）。

## 9 容器决策（6.1、6.2）

判定顺序（字段数只作初筛）：

1. 需要可回访链接、草稿、多阶段状态、长时编辑、复杂关联，或多分组/复杂校验/大编辑表格 → **独立页**（容量足够的 Drawer 亦可），保留上下文可用分区或参照面板。
2. 否则列表中单个对象的基础信息编辑、且一个任务内可完成 → **Modal【项目默认】**，保留列表筛选、页码、选择与滚动位置。
3. 否则需持续对照列表、连续切换处理对象 → 评估 **Drawer**，明确遮罩与焦点是否阻断主页面交互。
4. 否则单一短任务用 Modal；局部微操作可行内 / Popover。
5. 需同时操作主页面 → 行内 / 并排区域 / 经验证可交互的非模态面板。
6. 目标屏宽或文字缩放下内容不清楚、操作不可达 → 扩展布局或改独立页，不无限加宽弹窗。

| 容器 | 宽档 |
| --- | --- |
| Modal | S**400** / M**520**（默认）/ L**720** / XL**960**；默认 520px 即 SDK 默认，S400 ≠ confirm 默认 416 |
| Drawer | S**378** / M**480** / L**736** / XL**960**（378/736 为 preset default/large，480/960 为自定义候选） |

- 四周默认 **24px**，窄屏 **16px**；内容过高只滚内容区，标题与页脚可达；超出容量改独立页（6.2）。
- Drawer 可见主页面不代表主页面仍可交互；不能不判草稿/分享需求就直接选 Drawer（6.1）。

## 10 弹窗与抽屉结构（6.4）

- 类型：Confirm（是/否决策，无输入）、Dialog（展示需立即处理的信息）、表单 Modal（收集一个闭合任务的输入，无通用字段上限）、Drawer（持续对照/连续处理对象，或超出 Modal 合理容量）（6.4.1）。
- 结构：标题（h2 **16/24**，【强制】必须有，动词短语，禁止「提示」「系统消息」）→ 可选描述（base **14/22**，说明后果不重复标题）→ 内容区（超高超滚动）→ 底部操作区（**固定**，不随内容滚动）。
- Modal 外壳内距 **20/24px**（垂直/水平），内容区不重复叠加同一份内距；普通页脚不默认加分隔线，长表单固定页脚可用 1px `--ui-color-border`（3.3.8、5.6、6.4.2）。
- 顺序【强制】次操作在左、主操作在右；初始焦点给标题说明、首个字段或合适操作，表单不默认聚焦提交按钮；关闭后归还触发元素（6.4.3）。
- 危险操作（删除/停用）默认聚焦「取消」；按钮用 danger 并写具体后果（「删除 3 项」而非「确定」）（6.4.3）。
- 默认只允许一个任务型 Modal/Drawer；「丢弃修改」确认可为短暂第二层，完成后焦点归还原容器；选择器/日期/Tooltip 不按第二层计数（6.4.5）。
- 内容、错误与操作在目标视口可达；弹窗纵向伸缩，标题页脚不收缩，body 设 `min-height:0` + `overflow:auto`；窄屏按 4.3 收窄或改全屏面板/独立页，>70% 视口可先内容滚动（6.4.6、6.4.7）。

| 触发 | 确认任务 | 编辑任务 | 只读查看 |
| --- | --- | --- | --- |
| 关闭按钮 | 可用 | 可用，处理未保存修改 | 可用 |
| Esc | 取消/关闭 | 先关当前子浮层，再按未保存处理 | 关闭 |
| 遮罩点击 | 默认不执行确认动作 | 默认不直接关闭，避免误触丢输入 | 可关闭 |
| 浏览器返回 | 按路由 | 路由驱动，返回前保护未保存值 | 路由驱动，可返回关闭 |

列表「编辑」默认交互（6.4.8）：

| 容器与标题 | 居中表单 Modal，标题「编辑 + 对象」（如「编辑课件」），回填当前记录；列表保留在背景，不触发页面跳转 |
| 尺寸与底部 | 单列常规 **M520**，需文件摘要或合理双列用 **L720**；底部右对齐「取消」「保存修改」，标题与关闭入口始终可达 |
| 校验与保存后 | 错误就近、聚焦首错、保留输入、提交防重；成功后关闭并更新记录，按 8.2.4 保留筛选、页码、条数、有效选择与滚动位置 |
| 焦点 | 打开进入首个适用字段并限定在弹窗内；关闭返回触发的「编辑」，记录已离开结果则回列表标题 |

## 11 反馈方式选择（5.6、6.5）

| 反馈 | 用于 | 阻断 | 位置 |
| --- | --- | --- | --- |
| 内联错误 | 字段校验 | 否（阻断提交） | 字段正下方 |
| Message | 操作即时反馈 | 否 | 工程反馈区，时长按信息长度与是否可操作 |
| Alert | 持续可见的状态说明、表单级问题 | 否 | 页面/区块顶部，可关闭 |
| Notification | 后台完成、持续或系统消息 | 否 | 通常右上，重要/可操作消息持续到关闭 |
| Modal | 必须用户决策 | 是 | 居中 |
| Result 结果页 | 流程终态 | — | 独立页 |

- 【强制】错误一律就近：字段错误在字段下方，行操作失败在该行，禁止用统一 Message 报字段错误（6.5）。
- 成功提示能省则省：结果已在界面可见（列表多一行、开关变色）不再弹 Message；结果不在视野（「已导出，请到下载中心查看」）或有延迟时才用（6.5）。
- Alert 用于持续性状态（「该数据源近 7 天未同步」），不用于一次性事件；【强制】不用短暂 message 承载唯一撤销机会（5.6、6.5）。

## 12 危险操作与可逆性（6.6）

先问能不能撤销，再决定要不要确认。

| 级别 | 特征 | 交互 | 示例 |
| --- | --- | --- | --- |
| L1 可撤销 | 有明确逆操作 | 直接执行 + Message 内「撤销」 | 归档、置顶、标记已读 |
| L2 轻损失 | 删除但可恢复 | 一次 Confirm | 删除单条记录 |
| L3 重损失 | 删除且难恢复/影响他人 | Confirm + 输入名称或数量验证 | 删除部门、批量停用账号 |
| L4 不可逆 | 涉资金/权限/生产数据 | Confirm + 输入验证 + 结果通知，或走审批流 | 注销账号、清空数据 |

- 低影响且可靠可撤销的 L1 优先直接执行；涉及外部影响或撤销无法消除后果时仍评估风险（6.6）。
- 撤销窗口默认给足 **≥10s**，与短 Message 时长区分；可用持久结果区或回收站继续恢复（6.6）。
- 【强制】危险按钮不默认聚焦；批量确认必须带数量（「删除选中的 12 项」），禁止「确定删除吗？」（6.4.3、6.6）。
- 确认句式：`{动作}{对象名}？{后果}` → 「删除技术部？该部门下 8 名成员将被移出」（7.8.3）。

## 13 批量操作与选择模式（6.7）

- 行首复选框常驻；选中 ≥1 项后在**表格上方**出现操作条，表达「已选 N 项（范围）」+ 动作，超过 3 个动作收「更多」。
- 默认范围是**当前页**，表头复选框命名为「选择当前页全部项」；只有真实支持跨页才给「选择当前筛选结果全部 N 项」入口，并提供取消范围的方式。
- 翻页、排序、切换分组后按 8.2.4 处理选择集；【强制】选择集按稳定 ID 核对，不得用数组下标。
- 成功/失败/结果未知分别反馈：全部成功后清除已处理项；部分失败保留可见失败项并给逐项原因；未知项按 9.4 先查状态。
- 少量失败可就地列出；较多失败或异步任务可提供有权限控制的明细下载；重试只针对已确认可重试的失败项。

## 14 异步与长任务（6.8）

| 预估时长 | 交互 |
| --- | --- |
| <1s | 按钮 loading，无其他提示 |
| 1~10s | 按钮/相关区块 loading 与防重；不因一次提交把整页换成 Skeleton |
| 10s~2min | 进度条，允许在页面内操作其他内容 |
| >2min | 转后台任务 + Notification 通知结果，**允许离开页面** |

- 【强制】提交后立即禁用按钮并进入 loading，防重复提交是底线；>2min 任务必须提供任务中心/结果页入口（6.8）。
- 【强制】部分失败必须说明哪部分成功、哪部分失败，禁止笼统报「操作失败」（6.8）。
- 只有服务端已持久化才可承诺离页继续；路由切换停止无用轮询，任务中心可恢复查询（6.8、9.4）。

## 15 全局状态与异常（9.1—9.5）

核心原则：局部问题不升级成全局阻塞。

| 状态 | 呈现 | 操作 |
| --- | --- | --- |
| 加载 | 骨架屏（首次）/ 局部 Spin（刷新） | 无 |
| 空 | 插画 + 一句说明 + 最多 1 个主操作 | 新建 / 重置筛选 |
| 错误 | 图标 + 一句说明 + 重试 | 重试 / 返回 |
| 无权限 | 说明范围；申请入口按 7.6.2 | 真实可用的申请/联系路径或返回 |

| 粒度情形 | 处理 |
| --- | --- |
| 整页首次加载 / 关键数据失败 | 整页骨架屏 / 整页错误态 + 重试 |
| 单个区块加载 | **仅该区块**骨架屏，其他区块正常渲染 |
| 次要数据请求失败 | 该区块降级「暂不可用」，页面其余可用 |
| 多个区块同时失败 | 按是否致主任务整体不可用判断，独立次要区块分别降级 |

空态文案公式（【强制】说清是什么空、为什么空，不能只写「暂无数据」）：

| 场景 | 文案 + 操作 |
| --- | --- |
| 无数据 | 「暂无{对象}」+ [新建{对象}] |
| 筛选无结果 | 「没有找到符合条件的{对象}」+ [重置筛选] |
| 搜索无结果 | 「未找到「{关键词}」相关结果」+ [清空搜索] |
| 无权限 | 「你没有查看{对象}的权限」+ [真实可用的申请入口 / 返回] |

- 骨架屏 vs 转圈：首次加载、整块未就绪用 Skeleton；局部刷新、已有内容上的操作用 Spin；骨架形状接近真实内容；加载 >3s 叠加「加载中…」（9.2）。
- 【强制】禁止整页长期转圈（>3s 未出内容）与骨架长期占位无恢复路径（9.2）。

| 错误级别 | 示例 | 呈现 | 用户可做 |
| --- | --- | --- | --- |
| L1 字段级 | 必填未填、格式错 | 字段下方红字 | 就地修改 |
| L2 操作级 | 提交/删除失败 | Message / Alert + 重试 | 重试、修改后重试 |
| L3 区块级 | 某模块数据加载失败 | 区块内错误态 | 重试该区块 |
| L4 页面级 | 页面主数据失败 | 整页错误态 | 重试、返回列表 |
| L5 应用级 | 主任务整体不可用 | 应用级提示，保留可用导航/草稿 | 重连、返回、稍后再试 |

- 【强制】每级错误给出下一步动作，禁止只报「操作失败」；说明原因（「网络连接失败」优于「请求失败」），不暴露错误码与堆栈（9.3）。
- 写入超时/断网结果未知：不直接标失败并重发，先查任务/对象状态，用幂等键或服务端去重；网络恢复后重查并保留未保存输入，不自动整页刷新清空表单；10s/最多 1 次只是默认建议（9.4）。

- 错误页：404「页面不存在或已被移除」→ 返回首页/上一页；500「服务器开小差了，请稍后重试」→ 刷新/返回首页；无权限「你没有访问该页面的权限」→ 按 7.6.2 给真实申请/联系路径或返回；维护中「系统维护中，预计 {时间} 恢复」→ 无操作或联系管理员（9.5）。
- 【强制】错误页必须有导航出口，禁止只放一句话让用户卡死（9.5）。

## 16 表格四态与行内操作（8.4、8.5、8.1.4）

【强制】四态都保留表头可见（无权限态除外）。

| 状态 | 呈现 | 操作 |
| --- | --- | --- |
| 加载中 | 首次骨架屏，行数 = 当前页容量；刷新用表格上方细进度条或局部 Spin | 无 |
| 空·无数据 | Empty 插画 +「暂无数据」+ 主操作（如「新建订单」） | 新建 |
| 空·筛选无结果 | 空状态 +「没有找到符合条件的结果」+「重置筛选」 | 重置 |
| 错误 | 错误图标 +「加载失败」+「重试」 | 重试 |
| 无权限 | 说明范围，表体不披露无权数据 | 申请/返回，见 7.6.2 |

- 【强制】「无数据」与「筛选无结果」是两种空态：筛选无结果引导「重置筛选」，不要让用户去「新建」（8.4）。
- 骨架只替换表体、行数接近真实内容高度；错误态必须给「重试」；记录数为 0 时保留表头与当前条件（8.4）。
- 行内操作：最右固定列，文字按钮上限 **2 个**，超出收「更多」；高频（查看/编辑）前置，危险（删除）进「更多」；点击行内操作不得整行跳转，若支持整行进详情需 `stopPropagation`；纯图标必须有可访问名称（8.5）。
- 标识列固定左、操作列固定右；无溢出、已到边界或取消固定时不残留阴影（判定 `maxScroll = max(0, scrollWidth - clientWidth)`，`ε = 1px`）（8.1.4）。

## 17 常见反例库（6.9）

1. 多分组/编辑表格/复杂校验挤进小 Modal → 按 6.1 评估独立页或合适 Drawer，不是只按字段数选 720。2. 长流程无进度、不能回退、切步丢数据 → 明确流程状态与恢复，复杂任务优先独立页。3. 连续嵌套多个任务容器致焦点混乱 → 一个主任务容器，确认后归还原焦点。4. 遮罩/关闭直接丢弃未保存输入 → 关闭前保留或确认。5. 危险操作被默认 Enter 误触发 → 危险按钮不意外初始聚焦并说明后果。6. 删除只写「确定删除吗」→ 标明对象、数量、影响与恢复条件。
7. 低影响可撤销操作反复确认 → 直接执行并给足可达撤销入口。8. 所有字段错误只报一条 Message → 错误关联字段，必要时加汇总。9. 已明显可见的变化反复弹成功提示 → 保留必要状态反馈。10. 同一表单标签关系混乱 → 按信息分组统一标签布局。11. 用 opacity 覆盖整块禁用组件 → 沿用目标组件 disabled 与派生 Token。12. 比较数值难以纵向扫描 → 数字对齐并用等宽数字。
13. 提交期间可连续重复请求 → 前端防重 + loading + 服务端幂等。14. 批量部分失败只显示「失败」→ 区分成功/失败项并给恢复路径。15. 状态仅由色点表达 → 补文字/图标语义。16. 完整对象详情塞进狭小确认框 → 整页或足够容量面板并保留回访入口。17. 必需选择控件只有 hover 才出现 → 常驻或提供可发现、键盘可达入口。18. 需同时操作主页面却被 Drawer 遮罩阻断 → 验证并排/行内/无阻断面板的实际行为。
