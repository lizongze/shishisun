## 1 表单骨架（7.1 / 6.2 / 7.5）

| 项 | 值 | 强度 |
|---|---|---|
| 标签与控件间距 | 12px | 默认 |
| 字段与字段间距 | **24px** | 默认 |
| 控件与帮助/错误文本间距 | 4px | 默认 |
| 分组与分组间距 | 32px | 默认 |
| 分组标题与首字段间距 | 16px | 默认 |
| 操作区与字段区间距 | 32px | 默认 |
| 单列表单容器最大宽 | **640px** | 默认 |
| 双列表单容器最大宽 | 880px | 默认 |
| Modal 宽档 | S400 / M520 / L720 / XL960，未指定用 M520；弹窗内单列用 M520、双列用 L720 | 默认 |
| Drawer 宽档 | S320 / M480 / L720 / XL960 | 默认 |

- 强制：标题区顺序为 返回 + 标题 +（可选）一句话说明；组内顺序为 标签 → 控件 → 帮助文本。
- 标签与对齐（默认）：标签在控件上方、文字左对齐，字段整体左对齐；改左置标签时标签列宽按最长标签自适应，控件起点对齐。
- 单列/双列/分步判定：连续文本表单单列 640；字段需并排比较或配对用双列 880（12 栅格每列占 6）；阶段有依赖且能分批完成用分步，每步围绕一个阶段、最后一步才最终提交；表格、媒体、编辑器、窄容器按任务伸缩，不套 640/880。
- 操作区与吸底：独立表单页操作组左对齐，次操作在左、主操作在右；弹窗/抽屉右对齐，次序同为次左主右；原文未要求独立页吸底，弹窗/抽屉页脚强制不随内容滚动（页脚 flex:0 0 auto，仅内容区滚动），窄屏与文字放大下页脚仍可达。〔来源 7.1.1–7.1.2 / 6.2 / 7.5〕

## 2 字段规范（7.2）

| 档 | 宽度 | 适用字段 |
|---|---|---|
| 短 | 240px | 数量、金额、百分比、单个日期、编号 |
| 常规 | 400px | 名称、标题、短描述（单列可用 100%） |
| 长 | 100% | 长文本、Textarea、富文本、上传区 |

- 强制：同一行并排的同类字段宽度必须一致；双列两列等宽。240/400/100% 为候选档，220/280/320/360 等有依据的容器宽可用。
- 必填：红色 `*` 置于标签文字之前，色 `--ui-danger-6`；可选字段不加任何标记（禁止写"选填"）；全部必填时可在表单顶部写"以下均为必填项"并省略 `*`。
- 帮助文本：控件下方 12px `--ui-text-3`，一句话 ≤30 字，写"填什么/有什么限制"；长说明改"了解更多"链接。
- 占位符：只写格式示例（`YYYY-MM-DD`、`13800138000`、`示例：技术部`）；禁止代替标签、禁止与标签重复、禁止承载必要规则（规则进帮助文本）。
- 默认值与单位：能预判就给（当前日期、当前用户、上次选择），金额、权限、生效时间类默认值须业务方确认；单位写在标签括号或控件 suffix（`金额（元）`、`占比 %`），强制禁止写进占位符。
- 字段顺序：按填写心智 → 必填在前选填在后 → 被依赖字段在前 → 同类聚组 → 依赖未满足的字段置灰禁用，不让用户填完再报错。〔来源 7.2.1–7.2.6〕

## 3 校验、保存与提交（7.3 / 7.4）

| 时机 | 行为 |
|---|---|
| 输入过程中 | 不报错（禁止打一半就变红） |
| blur | 完成输入后的首次校验（默认） |
| 值变化 | 已有错误时重新校验；仅当当前值通过该规则才清除 |
| 提交 | 全量校验 |

- 例外：密码强度实时但用进度条/中性样式；唯一性查重 debounce **500ms**，loading 显示"检查中…"。
- 错误呈现：控件正下方 12px `--ui-danger-6` + 警示图标，控件边框同步 danger；多字段同时出错必须全部显示（句式见 §6）。
- 提交失败：滚动到第一个错误字段并聚焦；错误不在首屏时顶部 Alert"有 N 项需要修改"；服务端失败保持表单不关闭、数据不丢，顶部 Alert 显示服务端错误。
- 成功态：一般不显示绿色对勾；仅密码强度达标、唯一性通过给一次性正向反馈。
- 按钮与流程：文案用具体动词（创建订单、保存修改），主按钮只能一个、次操作 ≤2 个、超出收进"更多"；点击后立即 loading + 禁用（强制）→ 校验失败恢复按钮就近报错 → 成功关闭并刷新列表或跳结果/详情页。
- 禁用提交仅限权限不足、提交中、依赖未就绪，并在附近说明原因；危险/不可逆动作才做二次确认（句式见 §6）。
- 草稿：>20 字段或预计填写 >2 分钟 → 自动保存并显示"已自动保存 14:32"，间隔为停止输入后 3s 或每 30s；有未保存改动时离开必须确认"有未保存的修改，确定放弃？"；谨慎提供"重置"（误触清空全部输入），建议改"恢复默认值"。〔来源 7.3.1–7.3.3 / 7.4.1–7.4.3〕

## 4 只读 / 禁用 / 权限（7.6）

| 状态 | 含义 | 呈现 |
|---|---|---|
| 只读 | 已授权查看、当前不编辑 | 纯文本/Descriptions；需输入样式时用 readOnly；文本可选取复制 |
| 禁用 | 当前控件不可执行 | 原生 disabled；不承诺可聚焦/可复制，帮助信息放可达位置 |
| 无编辑权限但可查看 | 值可见、无修改权 | 纯文本或只读 + 说明 |
| 无查看权限 | 不得披露值 | 隐藏或脱敏 + 权限说明；服务端不返回无权数据 |

- 判定顺序：先看查看权，再看操作权与入口任务价值；强制禁止"无权限一律隐藏"或"不可执行一律置灰"的统一捷径；不要仅用 disabled 低对比展示详情值。
- 无操作权但能力需被发现/协作/申请 → 保留不可执行入口，原因用可见文字（不能只挂 hover Tooltip）。
- 无操作权且无发现、协作、恢复用途 → 隐藏该动作。
- 有操作权但业务条件暂不满足 → 禁用并给出业务条件，强制禁止写成"无权限"；无查看权时不显示假申请入口，前端表现不替代服务端鉴权。〔来源 7.6.1–7.6.2〕

## 5 键盘流（7.7）

| 按键 | 行为 |
|---|---|
| Tab / Shift+Tab | 按视觉顺序移动；强制禁止用 `tabindex` 强行改序 |
| Enter（单行控件） | 按表单任务触发预期动作；选择器/组合输入/中文输入法确认中不得误提交；搜索框触发查询 |
| Enter（Textarea） | 换行；Ctrl/Cmd+Enter 可快捷提交但须提示，不能作为唯一提交方式 |
| Esc | 弹窗/抽屉内取消（有未保存内容则拦截）；独立页不响应 |
| Space | 勾选框切换；按钮触发 |

- 焦点环：2px `--ui-primary-6` outline、偏移 2px；不得移除唯一可见焦点。〔来源 7.7〕

## 6 文案模板库（7.8 / 10.1）

- 必填与格式句式：输入类 `请填写{字段名}`、选择类 `请选择{字段名}`、上传类 `请上传{文件名}`；格式/范围如 `请输入 11 位手机号`、`仅支持字母、数字和下划线`、`最多可选择 5 项`。
- 冲突与逻辑句式：`工号 A1024 已被占用，请更换` / `结束日期不能早于开始日期`。
- 帮助文本句式：`用于{用途}`（用于登录时的身份校验）/ `支持{格式·范围}`（支持 JPG、PNG，单个不超过 5MB）/ `{默认行为}`（留空则默认跟随上级部门），一句为限。
- 危险确认句式：`{动作}{对象名}？{后果}` → `删除订单 1001？删除后不可恢复`；批量必须带数量 → `删除选中的 12 项`。
- 失败句式：`保存失败，请检查网络连接后重试`。
- 强制禁止：`格式错误`、`不能为空`、`输入不合法`、`已存在`、`超出限制`、`您确定要删除吗？`、`操作失败，请联系管理员`。〔来源 7.8.1–7.8.3 / 10.1〕

## 7 表格（8.1–8.5）

| 位置 | 内容 | 固定 |
|---|---|---|
| 最左 | 复选框（需批量操作时） | 固定左 |
| 左 | 标识列：ID / 编号 / 名称 | 强制固定左 |
| 中 | 主要属性、描述、状态 | 滚动 |
| 右 | 数值列、时间列 | 滚动 |
| 最右 | 操作列 | 强制固定右 |

| 内容类型 | 对齐 | 宽度 | 字体 |
|---|---|---|---|
| 文本（名称、描述） | 左 | 自适应 + 超出省略 | 常规 |
| 数值（金额、数量） | 右 | 固定宽 | tabular-nums |
| 状态（Tag、状态点） | 左（窄列可居中） | 按内容约束 | 常规 |
| 时间 | 左 | 固定宽（按格式长度） | tabular-nums |
| 操作 | 右 | 固定宽（按最长组合） | 常规 |

- 单位写进表头（`金额(元)`、`占比(%)`），不在单元格重复；表头 ≤6 字、用名词、不加"该/的"。
- 列数与单元格：默认只展示任务核心列，多列时提供列设置 + 横向滚动，不以 8 列为硬上限、不隐藏必需信息；强制禁止一格堆叠多个属性，主副信息用两行（主行 `text-1`、副行 `text-3` 12px）。

| 固定列右侧阴影 | 何时显示 |
|---|---|
| 全部列在可视宽度内、无横向溢出 | 隐藏 |
| 有溢出且右侧固定列仍遮住未滚入内容 | 显示 |
| 已滚到最右端、无剩余遮挡 | 隐藏 |
| 操作列已取消固定，或列表为空 | 隐藏 |

- 判定：`maxScroll = max(0, scrollWidth - clientWidth)`；仅当固定生效、有数据、`maxScroll > ε` 且 `maxScroll - max(0, scrollLeft) > ε` 时显示，默认 `ε = 1 CSS px`；用表格自身滚动容器测量；表头表体同状态；强制禁止给操作列长期挂装饰性阴影。

| 检索方式 | 位置 | 适用 | 生效时机 |
|---|---|---|---|
| 搜索 | 表格上方筛选区 | 关键词模糊匹配 | 回车或点"查询" |
| 筛选条件 | 筛选区 | 跨字段条件、日期范围 | 整组随"查询"统一应用 |
| 列筛选 | 表头 dropdown | 枚举值（状态、类型） | 立即生效 |

- 排序：仅时间、数值、有明确顺序的状态可排；三态循环 无 → 升序 → 降序 → 无；默认时间倒序；只对当前筛选结果生效；强制禁止给操作列、复选框列排序。
- 筛选条件常驻 ≤4 个，超出收进"高级筛选"；每行 ≤4 个控件且宽度一致；筛选后立即显示"共 N 条"。
- "重置"= 恢复已定义默认条件，"清空"= 清空全部值，两者不得混用。

| 数据特征 | 方式 |
|---|---|
| 常规业务列表 | 分页（可定位、返回、分享） |
| 需同屏对比多行 | 分页 + 大页容量 50/100 |
| 信息流、时间线、日志 | 滚动加载 |
| 单页 >200 行 | 虚拟滚动 |
| 需导出全量 | 分页 + 导出（导出不受分页限制） |

- 分页：默认每页 **10** 条，可选 10/20/50/100；显示"共 N 条"；>10 页开启快速跳页；翻页保留筛选与排序并回到表格顶部。
- 滚动加载：每次 ≤20 条，到底显示"没有更多了"，强制禁止无限自动加载，必须提供"回到顶部"。

| 状态 | 呈现 | 操作 |
|---|---|---|
| 加载中 | 首次用骨架屏（行数 = 当前页容量）；刷新用细进度条或局部 Spin | 无 |
| 空 · 无数据 | Empty 插画 + "暂无数据" + 主操作 | 新建订单 |
| 空 · 筛选无结果 | 空状态 + "没有找到符合条件的结果" | "重置筛选" |
| 错误 | 错误图标 + "加载失败" | "重试" |
| 无权限 | 说明范围，表体不披露数据 | 真实申请入口或返回路径 |

- 四态一律保留表头（无权限态除外）；强制禁止把"筛选无结果"做成"去新建"；骨架屏只替换表体，行数接近真实内容高度。
- 行内操作：最右固定列；文字按钮上限 **2 个**、超出收进"更多"；高频（查看/编辑）前置，危险（删除）强制放进"更多"；操作优先明确文字，纯图标必须有可访问名称（Tooltip 不能作为唯一名称）；点击行内操作不得整行跳转，若支持整行进详情则行内操作需 `stopPropagation`。

| 事件 | 筛选/排序 | 页码 / 条数 | 选择集 |
|---|---|---|---|
| 输入筛选未查询 | 结果不变，只更新草稿输入 | 不变 | 不变 |
| 查询 / 应用筛选 | 整组提交，保留分组与排序 | 第 1 页，条数保留 | 清当前页选择 |
| 重置筛选 | 恢复默认条件（非清空） | 第 1 页，条数保留 | 清除 |
| 改排序 | 条件与分组不变 | 第 1 页，条数保留 | 清当前页选择 |
| 翻页 / 改每页条数 | 不变 | 目标页 / 第 1 页，条数按设置 | 清当前页选择 |
| 保存后仍在结果 | 保留条件，按新值更新 | 尽量保留，超界校正 | 保留当前页有效 ID |
| 记录离开结果 | 保留条件，不放宽条件 | 夹取到有效页 | 移除该 ID |

- 批量部分失败：不改条件、不重发已成功项、未知项先查状态；详情返回恢复进入前的页、条数与滚动位置，触发元素消失时焦点回列表标题。
- 导出入口必须标明范围：`导出当前结果（N 项）`/`导出当前页（N 项）`/`导出已选（N 项）`；数量未知时不编造总数。〔来源 8.1–8.5〕

## 8 图表（8.6）

| 分析目的 | 图表 |
|---|---|
| 趋势 / 随时间变化 | 折线图 |
| 少量类别整体占比 | 饼图 / 环形图 |
| 较多类别占比 | 排序条形图（必要时评估堆叠条形图） |
| 对比类目 ≤12 | 柱状图 |
| 对比类目 >12、排名 | 横向条形图 |
| 相关性 / 分布 | 散点图 / 直方图 |
| 流程 / 转化 | 桑基图、漏斗图 |
| 单一完成度或占比 | Progress / Statistic（仪表盘、水波图需业务理由） |

- 配色与图例：走分类色板，同一指标跨页面颜色必须一致；轴标签 12px `--ui-text-3`、网格线 `--ui-border-1`、轴线 `--ui-border-2`；图例在右上或底部，不得遮挡数据、可点击切换；Tooltip 显示维度名 + 完整数值 + 单位，数值不缩写。
- 图表区最小高度 200px；切换筛选时高度不变；数据点 >50 关闭点标记；折线默认不显示数值标签；空数据居中"暂无数据"且不隐藏坐标轴。
- 强制禁止：3D 图表、彩虹配色、截断 Y 轴制造差异（除非明确标注不从 0 开始）、无坐标轴的柱状图；不默认使用双 Y 轴。〔来源 8.6.1–8.6.3〕

## 9 指标卡与数字（8.7 / 5.8.3）

| 场景 | 规则 | 示例 |
|---|---|---|
| 整数 | 千分位分隔 | 1,234,567 |
| 大数值 | ≥6 位自动缩写，hover 显示完整值 | 123.4 万 |
| 金额 | 默认 2 位小数，独立值标明币种/单位 | ¥1,200.00、金额（元） |
| 百分比 | 1 位小数 | 12.5% |
| 缺失 / 未知 | 显示 `--`；真实 0 仍显示 0 | `--` / 0 |
| 整数型度量 | 不显示小数；金额不因末尾为 0 省略精度 | 120 / ¥120.00 |

- 结构：标签 14px `--ui-text-2` 单行截断；数值 24/28px tabular-nums `--ui-text-1`；单位比数值小一档、间距 4px；同比环比 12px + ↑/↓；迷你图 ≤40px。
- 同一行卡片等高、数值基线对齐；卡片圆角 4、body 16（业务模板 6px 须单独登记）；数量上限为一屏 ≤6 个（看板）/ ≤4 个（首页一行）。
- 口径与配色：涨跌配色按方向与业务好坏配置，强制禁止套用"涨红跌绿"金融惯例；每个指标先登记 名称与对象 / 可见范围 / 纳入与排除 / 时间与时区 / 公式与精度 / 新鲜度 / 比较值 / 筛选关系 / 点击行为，再从本表取格式；时区默认 Asia/Shanghai，无有效基期时省略比较区，不编造增幅。〔来源 8.7.1–8.7.3 / 5.8.3〕

## 10 文案（10.1–10.6）

- 人称：对用户用"你"，强制不用"您"；陈述句为主，少用感叹号；说"能做什么"而非"不支持什么"；避免技术术语（用"导出表格"不用"生成 CSV"，用"恢复"不用"回滚事务"）。
- 术语统一：客户（禁 顾客/用户/商家）、订单（禁 交易单/业务单）、已完成（禁 结束/完结/done）、考试·培训·课程·练习按真实业务对象分别命名；同一概念全站只有一个叫法，新术语先登记。

| 动作 | 推荐文案 |
|---|---|
| 创建 / 修改 | 新建{对象} 或 创建{对象}（二选一全站统一）/ 编辑、保存修改 |
| 删除 / 提交 | 删除（配后果说明）/ 提交{对象}（必须带对象） |
| 审批 | 通过 / 驳回（不写"同意/不同意"） |
| 导入导出 / 检索 | 导入 / 导出（可加对象"导出报表"）/ 查询、搜索 |
| 启停 | 启用 / 停用（不写"激活/禁用"） |

- 按钮文案 = 动词 + 对象；避免"确认提交"式重复，不把"点击"当动作名。
- 标题句式：页面标题用具体名词（订单列表）、区块标题用名词短语（基础信息）、弹窗标题用动词短语（创建订单）、说明文字一句话说清后果（删除后该部门下 8 人将被移出）、空状态写"什么空 + 为什么空"（没有找到符合条件的订单）；强制禁止页面标题用"XX管理""XX信息"，弹窗标题用"提示""系统消息"。

| 场景 | 格式 | 示例 |
|---|---|---|
| 列表 | `MM-DD HH:mm` 或 `YYYY-MM-DD` | 10-28 16:30 |
| 详情 | `YYYY-MM-DD HH:mm:ss` | 2026-10-28 16:30:00 |
| 日期区间 | `YYYY-MM-DD ~ YYYY-MM-DD` | 2026-10-01 ~ 2026-10-28 |
| 相对时间 | ≤7 天用 今天/昨天/3 天前；>7 天改绝对日期 | 今天 16:30 / 2026-10-01 |
| 精确到天 | `YYYY-MM-DD` | 2026-10-28 |

- 单位与时间：单位紧跟数值、间隔 4px、字号小一档；金额 `¥1,200.00`（不加空格）；百分比 `12.5%`（不加空格）；中文场景用 `万`/`亿`，强制不用 `K`/`M`；时间列用等宽数字，默认时区 Asia/Shanghai，跨时区须说明来源与转换，日期型字段不得因时区误移一天。
- 多语言与截断：按真实长文案测布局（英文膨胀 40%–100% 不作通用保证）；按钮/标签强制禁止固定窄宽，用 padding 自适应；末尾截断保留前缀，全文须经 focus 提示、复制或详情可达；长标识可中间省略但必须能复制。〔来源 10.1–10.6〕

## 11 业务组件库要点（5.8）

| 组件 | 关键规则 |
|---|---|
| 通知公告 / 新闻动态 | 未读用左侧圆点，强制不用加粗；标题单行截断；缩略图 16:9 固定，强制禁止拉伸；空态"暂无公告" |
| 待办 | 逾期 `--ui-danger-6`、临期 `--ui-warning-6`；空态"暂无待办" |
| 待我审批 | 操作最多 2 个：通过 / 驳回 |
| 个人信息卡 | 头像 24/32/40/64，灰底 + 首字母，底色按用户 ID 稳定取色；姓名 16/24 500 |
| 快捷操作 | 最多 4 个，超出收进"更多"；最近访问 ≤8 个、按时间倒序 |
| 图表组件 | 注释 ≤2 处；下钻必须提供返回路径；空态"暂无数据" |
| 通用 | 每个业务组件必须定义数据上限（如"待办最多显示 5 条"），超出走"查看全部"；同行卡片等高、内容不足留白不拉伸 |
