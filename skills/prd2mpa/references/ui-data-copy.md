# UI 执行摘要：表单 / 表格 / 数据展示 / 文案

> 本文件压缩《UI规范文档》（2026-11 版，v4.0）第 7、8、10 章 + 5.8 业务组件组合 + 附录 A 变量，供 CDN React 18 + antd 6 手写多页原型快速执行；与原文冲突以原文为准。
> 用户自带 UI 规范时先按 [custom-ui-spec.md](custom-ui-spec.md) 处理，再照本文件结构重做一份项目版。
> 原文未规定的按 antd 6 默认，不自行发明；数值单位均为 CSS px；出处为章节号。
> 标注：【项目默认】= 可覆盖但须在页面记录登记原因与适用范围；【强制】= 原文必须/禁止（0.3）。

## 1 表单骨架（7.1、6.3）

| 项 | 值 | 强度 |
| --- | --- | --- |
| 单列表单容器最大宽 | **640px** | 默认 |
| 双列表单容器最大宽 | 880px | 默认 |
| 标签与控件间距 | **12px**（`--ui-space-12`，覆盖 SDK verticalLabelPadding） | 默认 |
| 字段与字段间距 | **24px** | 默认 |
| 控件与帮助/错误文本间距 | 4px | 默认 |
| 分组与分组间距 | **32px** | 默认 |
| 分组标题与首字段间距 | 16px | 默认 |
| 操作区与字段区间距 | 32px | 默认 |
| 控件高度（small/medium/large） | **24 / 32 / 40**，默认 medium | 默认 |
| 控件圆角 | **6px** | 默认 |

- 标题区顺序【强制】返回 + 标题 +（可选）一句话说明；组内顺序为 标签 → 控件 → 帮助文本（7.1.1）。
- 单列/双列/分步判定：连续文本填写优先单列；字段短、关联清楚且空间足够可双列（12 栅格每列占 6）；阶段有依赖且可分批完成用分步，最后一步才最终提交（6.3.1、7.5）。
- 操作区：独立表单页操作组**左对齐**，组内次操作在左、主操作在右；弹窗/抽屉**右对齐**、固定底部；独立页跟随内容或吸底；表格、媒体、编辑器、窄容器按任务伸缩，不套 640/880（6.3.5、7.4.1）。

## 2 字段规范（7.2）

| 档 | 宽度 | 适用字段 |
| --- | --- | --- |
| 短 | **240px** | 数量、金额、百分比、单个日期、编号 |
| 常规 | **400px** | 名称、标题、短描述（单列可用 100%） |
| 长 | 100% | 长文本、Textarea、富文本、上传区 |

- 【强制】同一行并排的同类字段宽度必须一致；双列两列等宽；240/400/100% 是候选档，280/320/360 等按内容确定的宽度可用（7.2.1）。
- 必填：红色 `*` 置于**标签文字之前**，色 `--ui-color-error`；可选字段**不做任何标记**（禁止写「选填」）；全部必填时可在表单顶部注明「以下均为必填项」并省略 `*`（7.2.2）。
- 帮助文本：控件下方 **12px**、色 `--ui-color-text-tertiary`，一句话 **≤30 字**，写「填什么/有什么限制」；长说明改「了解更多」链接（7.2.3）。
- 默认值与单位：能预判就给（当前日期、当前用户、上次选择）；金额、权限、生效时间类默认值须业务方确认；单位放**标签括号**或控件 suffix（`金额（元）`、`占比 %`），【强制】禁止写进占位符（7.2.5）。

| 占位符用法 | 判定 |
| --- | --- |
| 示意格式：`YYYY-MM-DD`、`13800138000`、`示例：技术部` | ✅ 用 |
| 代替标签、只用占位符说明含义 | ❌【强制】禁止 |
| 与标签重复（标签「姓名」+ 占位符「姓名」） | ❌【强制】禁止 |
| 承载必要规则（「至少 8 位，含大小写」） | ❌【强制】禁止，规则进帮助文本 |

- 字段顺序：按填写心智 → 必填在前选填在后 → 被依赖字段在前 → 同类聚组 → 依赖未满足时置灰禁用，不让用户填完再报错（7.2.6）。

## 3 校验、保存与提交（7.3、7.4）

| 时机 | 行为 |
| --- | --- |
| 输入过程中 | **不报错**（禁止打一半就变红） |
| 失焦 blur | 完成输入后的首次校验（默认） |
| 值变化时 | 已有错误时重新校验；**仅当当前值通过该规则**才清除 |
| 提交时 | 全量校验 |

- 例外：密码强度实时但用进度条/中性样式；唯一性查重 debounce **500ms**，loading 显示「检查中…」（7.3.1）。
- 错误呈现：控件**正下方 12px** `--ui-color-error` + 警示图标，控件边框同步 error；多字段同时出错必须**全部显示**（7.3.2）。
- 提交失败：滚动到第一个错误字段并聚焦；错误不在首屏时顶部 Alert「有 N 项需要修改」；服务端失败保持表单不关闭、数据不丢，顶部 Alert 显示服务端错误（7.3.2、7.4.2）。
- 成功态：一般不显示绿色对勾；仅密码强度达标、唯一性通过给一次性正向反馈（7.3.3）。
- 提交流程【强制】：点击后立即 loading + 禁用 → 校验失败恢复按钮并就近报错 → 成功则弹窗/抽屉关闭并刷新列表，独立页跳结果页或详情页（7.4.2）。

| 草稿场景 | 策略 |
| --- | --- |
| 简短且可轻易重填 | 可不提供草稿，按中断成本决定 |
| >20 字段，或预计填写 >2 分钟 | **自动保存**，显示「已自动保存 14:32」 |
| 富文本 / 多附件 / 中断成本高 | 优先持久化，明确存储、恢复与权限边界 |

- 自动保存间隔：停止输入后 3s，或每 30s；有未保存改动时离开必须确认「有未保存的修改，确定放弃？」（7.4.3）。
- 谨慎提供「重置」（误触清空全部输入），建议改「恢复默认值」或直接不提供（7.4.3）。
- 禁用提交仅限权限不足、提交中、依赖未就绪，并在附近说明原因，不让用户猜（7.4.2）。

## 4 只读 / 禁用 / 权限（7.6）

| 状态 | 含义 | 呈现 |
| --- | --- | --- |
| 只读 | 已授权查看、当前不编辑 | 纯文本 / Descriptions；需输入样式时用 readOnly；文本可选取复制 |
| 禁用 | 当前控件不可执行 | 原生 disabled；不承诺可聚焦/可复制，帮助信息放可达位置 |
| 无编辑权限但可查看 | 值可见、无修改权 | 纯文本或只读 + 按需说明 |
| 无查看权限 | 不得披露值 | 隐藏 / 脱敏 / 权限说明；服务端不返回无权数据 |

| 条件 | 默认呈现 |
| --- | --- |
| 无查看权 | 不展示无权值；必要时给范围说明或返回路径；可申请时才给真实入口 |
| 有查看权、无操作权，且需发现/协作/申请 | 保留不可执行入口 + 可达原因，或提供真实申请/联系路径 |
| 无操作权，且无发现/协作/恢复用途 | 隐藏该动作 |
| 有操作权，业务条件暂不满足 | 条件说明有助下一步时禁用（永久不适用可隐藏），给出业务条件 |
| 提交中或依赖未就绪 | 临时不可执行并显示进度/原因，结束后恢复或给真实错误 |

- 先判查看权，再判操作权与入口价值；【强制】禁止「无权限一律隐藏」「不可执行一律置灰」的统一捷径（7.6.2）。
- 【强制】不只用 disabled 低对比展示详情值；原因说明须可见或键盘/触屏可达，不能只挂 disabled 按钮的 hover Tooltip（7.6.1、7.6.2）。
- 前端表现不替代服务端鉴权；申请、转交、复制等替代入口仅在真实支持且有权使用时提供（7.6.2）。

## 5 键盘流（7.7）

| 按键 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 按**视觉顺序**移动；【强制】禁止用 `tabindex` 强行改序 |
| Enter（单行控件） | 按表单任务触发预期动作；选择器/组合输入/中文输入法确认中不得误提交；搜索框触发查询 |
| Enter（Textarea） | 换行；Ctrl/Cmd+Enter 可快捷提交但须提示，不能作为唯一提交方式 |
| Esc | 弹窗/抽屉内取消（有未保存内容则拦截，见 6.4.4）；独立页不响应 |
| Space | 勾选框切换；按钮触发 |

- 焦点环：2px `--ui-color-primary` outline、偏移 2px；不得移除唯一可见焦点，可替换但须提供等效 focus-visible 指示（7.7）。

## 6 文案模板库（7.8、10.1）

| ❌ 不要 | ✅ 要 |
| --- | --- |
| 格式错误 | 请输入 11 位手机号 |
| 不能为空 | 请填写部门名称 |
| 输入不合法 | 仅支持字母、数字和下划线 |
| 已存在 | 工号 A1024 已被占用，请更换 |
| 超出限制 | 最多可选择 5 项 |
| 日期错误 | 结束日期不能早于开始日期 |

- 必填句式：输入类 `请填写{字段名}`、选择类 `请选择{字段名}`、上传类 `请上传{文件名}`（7.8.1）。
- 帮助文本句式：`用于{用途}` / `支持{格式·范围}` / `{默认行为}`（如「留空则默认跟随上级部门」），一句为限（7.8.2）。
- 提交按钮句式：`{动词}{对象}` → 创建订单、保存修改、提交审批（7.8.3）。
- 危险确认：`{动作}{对象名}？{后果}` → 「删除技术部？该部门下 8 名成员将被移出」；批量必须带数量「删除选中的 12 项」（7.8.3、6.6）。
- 【强制】禁止「操作失败，请联系管理员」这类无下一步、无原因的泛化文案；失败写「保存失败，请检查网络连接后重试」（7.8.1、10.1）。

## 7 表格（8.1—8.5）

| 位置 | 内容 | 是否固定 |
| --- | --- | --- |
| 最左 | 复选框（如需批量操作） | 固定 |
| 左 | **标识列**：ID / 编号 / 名称 | **固定左** |
| 中 | 主要属性、描述 | 滚动 |
| 中 | 状态列 | 滚动 |
| 右 | 数值列、时间列 | 滚动 |
| 最右 | 操作列 | **固定右** |

- 表格组件：列表默认 **size="medium"**，cell padding **12/8**，14/22 文字、表头 600，单行高约 **47**；表头底 `Table.headerBg` **#FAFAFA**，边界 `--ui-color-border-secondary` **#F0F0F0**，控件/单元格描边 **#D9D9D9**（4.4、5.5.1）。

| 内容类型 | 对齐 | 宽度 | 字体 |
| --- | --- | --- | --- |
| 文本（名称、描述） | **左** | 自适应 + 超出省略 | 常规 |
| 数值（金额、数量） | **右** | 固定宽 | tabular-nums |
| 状态（Tag、状态点） | 默认左，窄工具列可居中 | 按内容约束 | 常规 |
| 时间 | 左 | 固定宽（按格式长度） | tabular-nums |
| 操作 | **右** | 固定宽（按最长组合） | 常规 |

- 单位写进**表头**（`金额(元)`、`占比(%)`），不在单元格重复；表头 ≤6 字、用名词、不加「该/的」（8.1.2）。
- 普通正文列（含创建时间/更新时间）统一用 `colorText`，不因是时间就弱化或缩小字号（8.1.2）。
- 默认只展示任务核心列；多列时给列设置 + 横向滚动，不以 8 列为硬上限、不隐藏必需信息；【强制】禁止一格堆叠多个属性，主副信息用两行（主行 `colorText`、副行 `colorTextTertiary` 12px）（8.1.3）。

| 固定列右侧阴影 | 何时显示 |
| --- | --- |
| 全部列在可视宽度内、无横向溢出 | 隐藏 |
| 有溢出且右侧固定列仍遮住未滚入内容 | 显示 |
| 已滚到最右端、无剩余遮挡 | 隐藏 |
| 操作列已取消固定或列表为空 | 隐藏 |

- 判定：`maxScroll = max(0, scrollWidth - clientWidth)`；仅当固定生效、有数据、`maxScroll > ε` 且 `maxScroll - max(0, scrollLeft) > ε` 时显示，默认 `ε = 1px`；测量表格自身滚动容器；表头表体同状态；【强制】禁止给操作列长期挂装饰性阴影（8.1.4）。

| 检索方式 | 位置 | 适用 | 生效时机 |
| --- | --- | --- | --- |
| 搜索 | 筛选区（表格上方） | 关键词模糊匹配 | 回车或点「查询」 |
| 筛选区条件 | 筛选区 | 跨字段条件、日期范围 | 有「查询」按钮时整组统一应用 |
| 列筛选 | 表头 dropdown | 枚举值（状态、类型） | 立即生效 |

- 排序：仅时间、数值、有明确顺序的状态可排；三态循环 无 → 升序 → 降序 → 无；默认**时间倒序**；只对当前筛选结果生效；【强制】禁止给操作列、复选框列排序（8.2.2）。
- 筛选：常驻 **≤4 个**，超出收「高级筛选」；每行默认 ≤4 项且用同一组等宽栅格，末行不足不拉伸；行/列间隙 **12px**；操作位独立不计入等宽列；筛选后立即显示「共 N 条」（8.2.3）。
- 「重置」= 恢复已定义默认条件，「清空」= 清空全部值，两者不得混用；【强制】敏感筛选值不进 URL，可分享视图只写入非敏感状态（8.2.3）。

| 事件 | 条件 / 排序 | 页码 · 条数 | 选择集 |
| --- | --- | --- | --- |
| 输入筛选未查询 | 结果不变，仅更新草稿输入 | 不变 | 不变 |
| 查询 / 应用筛选 | 整组提交，保留分组与排序 | 第 1 页，条数保留 | 清除当前页选择 |
| 重置筛选 | 恢复默认条件（非清空） | 第 1 页，条数保留 | 清除 |
| 切换分组 / 分类 | 保留兼容条件与排序，不适用项清除并说明 | 第 1 页，条数保留 | 清除 |
| 改排序 | 条件与分组不变 | 第 1 页，条数保留 | 清除当前页选择 |
| 翻页 / 改条数 | 不变 | 目标页 / 第 1 页 | 清除当前页选择 |
| 打开 / 取消编辑 | 不改列表上下文 | 不变 | 保留有效 ID |
| 保存后仍在结果 | 保留条件，按新值更新 | 尽量保留，超界校正 | 保留当前页有效 ID |
| 记录离开结果 | 保留条件，不放宽条件 | 夹取到有效页 | 移除该 ID |
| 从详情返回 | 恢复进入前上下文 | 恢复有效页与条数 | 恢复有效 ID |
| 批量部分失败 | 不改条件，不重发成功项 | 校正有效页 | 成功项移除、失败项保留、未知先查 |
| 导出 | 明确当前页 / 当前结果 / 已选范围 | 不影响列表 | 不改变 |

- 【强制】选择集按稳定 ID 核对，不得用数组下标；查询失败不得把原选择映射到其他记录；记录数 0 时保留表头与当前条件（8.2.4）。
- 导出入口必须标明范围：`导出当前结果（N 项）`/`导出当前页（N 项）`/`导出已选（N 项）`；数量未知时不编造总数（8.2.4）。

| 数据特征 | 方式 |
| --- | --- |
| 常规业务列表（默认） | 分页（可定位、返回、分享） |
| 需同屏对比多行 | 分页 + 大页容量 50/100 |
| 信息流、时间线、日志 | 滚动加载 |
| 单页 >200 行 | 虚拟滚动 |
| 需导出全量 | 分页 + 导出（导出不受分页限制） |

- 分页：默认每页 **10** 条，可选 10/20/50/100；显示「共 N 条」；>10 页开启快速跳页；翻页保留筛选与排序并回到表格顶部；分页在**右下、与表格间距 12px**（4.2.1、8.3）。
- 滚动加载：每次 ≤20 条，到底显示「没有更多了」；【强制】禁止无限自动加载，必须提供「回到顶部」（8.3）。

| 状态 | 呈现 | 操作 |
| --- | --- | --- |
| 加载中 | 首次骨架屏（行数 = 当前页容量）；刷新用细进度条或局部 Spin | 无 |
| 空 · 无数据 | Empty 插画 +「暂无数据」+ 主操作 | 新建订单 |
| 空 · 筛选无结果 | 空状态 +「没有找到符合条件的结果」 | 重置筛选 |
| 错误 | 错误图标 +「加载失败」 | 重试 |
| 无权限 | 说明范围，表体不披露数据 | 真实申请入口或返回路径 |

- 【强制】四态一律保留表头（无权限态除外）；禁止把「筛选无结果」做成「去新建」；骨架只替换表体、行数接近真实内容（8.4）。
- 行内操作：最右固定列；文字按钮上限 **2 个**，超出收「更多」；高频（查看/编辑）前置，危险（删除）进「更多」；操作优先明确文字，纯图标必须有可访问名称；点击行内操作不得整行跳转，若支持整行进详情需 `stopPropagation`（8.5）。

## 8 图表（8.6）

| 分析目的 | 图表 |
| --- | --- |
| 趋势 / 随时间变化 | **折线图** |
| 少量类别整体占比 | 饼图 / 环形图 |
| 较多类别占比 | 排序条形图（需要整体构成时评估堆叠条形图） |
| 数值对比（类目 ≤12） | 柱状图 |
| 数值对比（类目 >12）、排名 | **横向条形图** |
| 相关性 / 分布 | 散点图 / 直方图 |
| 流程 / 转化 | 桑基图、漏斗图 |
| 单一完成度或占比 | 优先 Progress / Statistic（仪表盘、水波图需业务理由） |

- 配色走分类色板（3.3.6）；同一指标跨页面颜色必须一致；轴标签 12px `--ui-color-text-tertiary`、网格线 `--ui-color-border-secondary`、轴线 `--ui-color-border`（8.6.2）。
- 图例在右上或底部，不得遮挡数据、可点击切换；Tooltip 显示维度名 + 完整数值 + 单位，数值不缩写；数据点 >50 关闭点标记；折线默认不显示数值标签（8.6.2）。
- 图表区最小高度 **200px**；切换筛选/时间范围时高度不变；数值精度：金额 2 位小数、百分比 1 位、整数不带小数；空数据居中「暂无数据」且不隐藏坐标轴（8.6.2）。
- 【强制】禁止 3D 图表、彩虹配色、截断 Y 轴制造差异（未标注不从 0 开始）、无坐标轴的柱状图；不默认使用双 Y 轴（8.6.3）。

## 9 指标卡与数字（8.7、5.8.3）

| 场景 | 规则 | 示例 |
| --- | --- | --- |
| 整数 | 千分位分隔 | 1,234,567 |
| 大数值 | ≥6 位自动缩写，hover/focus 或详情显示完整值 | 123.4 万 |
| 金额 | 默认 2 位小数；独立值明确币种/单位 | ¥1,200.00 / 金额（元） |
| 百分比 | 1 位小数 | 12.5% |
| 未知 / 缺失 | 显示 `--`；真实 0 仍显示 0 | `--` / 0 |
| 整数型度量 | 不显示小数；金额不因末尾为 0 省略精度 | 120 / ¥120.00 |

| 元素 | 规格 |
| --- | --- |
| 标签 | 14px `--ui-color-text-secondary`，单行截断 |
| 数值 | 默认 **24/32**，必要时 30/38；tabular-nums、`--ui-color-text` |
| 单位 | 比数值小一档，间距 4px |
| 同比环比 | 有有效基期才提供；12px + ↑/↓，按方向与业务好坏配色 |
| 迷你图 | 可选，高度 ≤40px，不抢主数值 |
| 卡片 | 圆角 **8px**、body **24px** |

- 同一行指标卡数值基线对齐、字号一致、卡片等高；一屏 ≤6 个（看板）或 ≤4 个（首页一行）（8.7.2）。
- 【强制】涨跌配色按方向与业务好坏配置，禁止套用「涨红跌绿」金融惯例（8.7.2）。

| 口径定义项 | 必须说明 |
| --- | --- |
| 名称与对象 | 计数的是客户、订单、任务还是金额；名称与单位是否准确 |
| 可见范围 | 个人/团队/组织/全局；始终受当前用户查看权限限制 |
| 纳入与排除 | 是否含公海、归档、取消、停用；按什么稳定标识去重 |
| 时间与时区 | 统计时点或时段、字段、起止边界、时区与精度（默认 Asia/Shanghai） |
| 公式与精度 | 分子、分母、汇总方式、单位；分母为 0、缺失与真实 0 如何处理 |
| 新鲜度 | 数据来源、截至时间或更新方式；不显示虚假实时状态 |
| 比较值 | 基期与可比性；无有效基期时省略或明确不可比较 |
| 筛选关系 | 是否继承分组与已应用筛选；未提交的筛选输入不改变指标 |
| 点击行为 | 是否可点击、目标视图、带入条件与返回路径；无目标不给伪入口 |

- 【强制】口径未定义时仅展示已定义的列表结果数，不编造公式或趋势（8.7.3）。

## 10 文案（10.1—10.6）

- 人称：对用户用「你」，【强制】不用「您」；陈述句为主，少用感叹号；说「能做什么」而非「不支持什么」；避免技术术语（「导出表格」不用「生成 CSV」，「恢复」不用「回滚事务」）（10.1）。
- 【强制】「系统暂不支持该功能」要改说当前可用替代路径，只有已确认计划才承诺版本上线（10.1）。

| 概念 | 统一叫法 | 禁止别名 |
| --- | --- | --- |
| 客户 | 客户 | 顾客、用户、商家 |
| 订单 | 订单 | 交易单、业务单 |
| 状态·已完成 | 已完成 | 结束、完结、done |
| 考试 / 培训 / 课程 / 练习 | 按真实业务对象分别命名 | 用「用户/客户/记录」笼统替代不同对象 |

- 【强制】同一概念全站只有一个叫法，新增术语先登记；评审重点查「同一页面里同一个东西两种叫法」（10.2）。

| 动作 | 推荐文案 |
| --- | --- |
| 创建 / 修改 | 新建{对象} 或 创建{对象}（二选一全站统一）/ 编辑、保存修改 |
| 删除 / 提交 | 删除（配后果说明）/ 提交{对象}（必须带对象） |
| 审批 | 通过 / 驳回（不写「同意/不同意」） |
| 导入导出 / 检索 | 导入 / 导出（可加对象）/ 查询、搜索 |
| 重置 / 取消 / 上传 | 重置（恢复默认筛选）/ 取消 / 上传{文件类型} |
| 启停 | 启用 / 停用（不写「激活/禁用」） |

- 按钮文案 = 动词 + 对象；避免「确认提交」式重复，不把「点击」当动作名；语境清楚的「确定」「完成」「是/否」可以使用（10.3）。

| 元素 | 句式 | 示例 |
| --- | --- | --- |
| 页面标题 | 具体名词 | 订单列表、客户详情 |
| 区块标题 | 名词短语 | 基础信息、操作日志 |
| 弹窗标题 | 动词短语 | 删除部门、创建订单 |
| 说明文字 | 一句话说清用途或后果 | 删除后该部门下 8 人将被移出 |
| 空状态 | 什么空 + 为什么空 | 没有找到符合条件的订单 |

- 【强制】禁止页面标题用「XX管理」「XX信息」，弹窗标题用「提示」「系统消息」（10.4）。

| 场景 | 格式 | 示例 |
| --- | --- | --- |
| 列表 | `MM-DD HH:mm` 或 `YYYY-MM-DD` | 10-28 16:30 |
| 详情 | `YYYY-MM-DD HH:mm:ss` | 2026-10-28 16:30:00 |
| 日期区间 | `YYYY-MM-DD ~ YYYY-MM-DD` | 2026-10-01 ~ 2026-10-28 |
| 相对时间（≤7 天） | 今天 / 昨天 / 3 天前 | 今天 16:30 |
| 相对时间（>7 天） | 改绝对日期 | 2026-10-01 |
| 精确到天 | `YYYY-MM-DD` | 2026-10-28 |

- 单位：紧跟数值、间隔 4px、字号小一档；金额 `¥1,200.00`（不加空格）；百分比 `12.5%`（不加空格）；中文场景用 `万`/`亿`，【强制】不用 `K`/`M`（10.5.3）。
- 时间列用等宽数字；默认时区 Asia/Shanghai，跨时区须说明来源与转换，日期型字段不得因时区误移一天（10.5.2）。
- 多语言与截断：按真实长文案测布局（英文膨胀 40%–100% 不作通用保证）；按钮/标签【强制】禁止固定窄宽，用 padding 自适应；末尾截断保留前缀，全文须可经 focus、复制或详情获取；长标识可中间省略但原文必须可取（10.6）。

## 11 业务组件库要点（5.8）

| 组件 | 必备元素 / 空状态 | 关键规则 |
| --- | --- | --- |
| 通知公告 / 重要通知 | 标题、时间、未读标记 / 「暂无公告」 | 未读用左侧圆点，不用加粗；标题单行截断 |
| 公文 / 新闻动态 | 文号与时间 / 缩略图、标题、来源 / 「暂无公文」「暂无动态」 | 文号用等宽数字；缩略图 16:9 固定，禁止拉伸 |
| 消息中心 / 常见问题 | 类型图标、内容、已读态 / 「暂无消息」 | 未读数用 Badge；FAQ 默认收起 |
| 待办事项 | 标题、来源、截止时间、紧急度 / 「暂无待办」 | 逾期 `--ui-color-error`、临期 `--ui-color-warning` |
| 我的任务 / 我的日程 | 状态与进度 / 时间轴升序 | 状态：未开始 / 进行中 / 已结束 |
| 待我审批 | 申请人、类型、提交时间 / 「暂无待审批」 | 操作最多 2 个：通过 / 驳回 |
| 指标卡（主数据） | 指标名、数值、单位、数据范围 / 数值 `--` | tabular-nums + 千分位；比较值仅在有效基期时提供 |
| 数据概览 / 数据总览 | 多指标组合、时间范围切换 | 一屏 ≤6 个指标 |
| 快捷入口 / 快捷操作 | 图标、名称 / 说明或可添加入口 | 网格排列末行可留空；快捷操作 ≤4 个，超出收「更多」 |
| 我的常用 / 最近访问 | 应用图标、名称 / 「暂无记录」 | 最近访问按时间倒序，≤8 个 |
| 个人信息卡 / Avatar | 头像 24/32/40/64、姓名、部门 / 默认灰底 + 首字母 | 姓名 `colorText` 16/24 600；底色按用户 ID 稳定取色 |
| 图表（通用） | 图表、单位、图例、坐标轴 / 「暂无数据」 | 配色走 3.3.6；同指标跨页一致；下钻必须提供返回路径 |
| 排行榜 / banner | 排名、名称、数值 / 按数据为空处理 | 前三名特殊标识；banner 无数据则隐藏整块，不在小卡片内用大 banner |
| AI 卡片 | 文案、输入入口、示例问题 | 整卡可点；示例问题 ≤3 个 |

- 【强制】每个业务组件必须定义**数据上限**（如「待办最多显示 5 条」），超出走「查看全部」；同一行卡片等高，内容不足留白不拉伸（5.8.8）。
- 任务状态色按 5.1.5：未开始中性、进行中 colorPrimary、成功完成 colorSuccess、逾期 colorError；「已结束」属取消/归档时不自动套成功色（5.8.2）。
- 容器圆角 8px、Card body 24px；静态导航与装饰无需取数状态（5.8）。
